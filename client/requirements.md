## Packages
leaflet | Core mapping library
react-leaflet | React components for Leaflet maps
recharts | For visualizing earnings data and trends
framer-motion | For smooth animations and transitions
date-fns | For date formatting and manipulation
lucide-react | Beautiful icons (already in base, but listing for completeness)
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging Tailwind classes efficiently

## Notes
- Map requires 'leaflet/dist/leaflet.css' to be imported in index.css or main entry point.
- Dark mode is default or strongly preferred for night driving context.
- Leaflet map centered on Krakow, Poland (50.0647, 19.9450).
- Authentication uses Replit Auth (cookies), so fetch credentials: "include" is required.
